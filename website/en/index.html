Read formation codes from a running game or apply the current formation. Check the docs for supported versions and limitations.

Extract. Open. Start planting.

  1. Download and fully extract the ZIP. Keep the DLL files and data folder alongside the app.
  2. Run pvz_formation_editor.exe, choose a scene and edit your formation.
  3. Use Load / Export to copy formation codes, export images or read a formation from the game.
