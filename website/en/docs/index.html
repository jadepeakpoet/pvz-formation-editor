USER GUIDE / 1.0.2

Your first desktop formation

A local Flutter Widget / Canvas formation editor with editing, autosave, 363 presets, formation codes, image export and Windows game integration.

Download and run · Editing · Load / Export · Game integration · Archives · FAQ

Platforms and verification

Windows is the primary platform, targeting Windows 10 / 11 x64. Release builds, desktop windows, autosave, import/export and real 1051 game read/write have been verified. Live game read/apply and game-save integration are Windows-specific.

Projects are included for Windows, macOS, Linux, Android and iOS. macOS 12.0+ downloads are available for Apple Silicon arm64 and Intel x64. Both packages pass architecture, signature and ZIP-integrity checks. The Apple Silicon ZIP has been extracted and launched; native Intel execution is not yet verified. Linux, Android and iOS await build and device validation.

Download and run

Windows 10 / 11 x64

  1. Download the Windows x64 ZIP and extract it to a writable folder.
  2. Open pvz_formation_editor.exe. Keep all included DLL files and the data folder alongside it; do not run only the EXE from inside the ZIP.
  3. The main board and sidebar work together. The Archive Library tab sits to the left of Layout Presets. About, at the top of the main window, links to the docs and project.

If your browser blocks the site download, use the GitHub download.

Windows 10 / 11 x64 is supported. No installation is needed, but local data is stored in your user application-data folder. Moving the app does not move your archives; export the data you want to keep before migrating.

macOS 12.0 or later

  1. Check Apple menu → About This Mac. Download Apple Silicon arm64 or Intel x64 for your chip.
  2. Extract the ZIP and move PVZ Formation Editor.app to Applications.
  3. Packages are ad-hoc signed without Developer ID signing or Apple notarization. If blocked on first launch, verify the SHA-256 checksum and source, then choose Open Anyway for this app in System Settings → Privacy & Security.

GitHub alternatives: Apple Silicon · Intel. Local editing, archives, code exchange and image export are supported. Live-game read/apply and game-save directory integration require Windows. Application files and archives are separate; export your data before moving devices.

The app is “damaged” or cannot be opened

First compare the ZIP with its published SHA-256 checksum. Download it again if the checksum differs. If it matches and you have confirmed the official source, first try Open Anyway for this app in System Settings → Privacy & Security. If that option is unavailable, remove the download quarantine flag for this app only:

xattr -dr com.apple.quarantine '/Applications/PVZ Formation Editor.app'

Adjust the app path if you installed it elsewhere. This does not require sudo or disable Gatekeeper globally. Quarantine is only one possible cause; a checksum mismatch, broken extraction or invalid signature requires a fresh download or an issue report, rather than assuming every warning is a false alarm.

Editing formations

Choose a scene, plant and placement tool to build your layout. The toolbox opens on the plant encyclopedia by default and also provides layout presets, display options, mirrored views and image export. Soil splashes are off by default. Undo and redo are available. Edits are saved automatically to the local archive, with a save status at the top of the main window. A failed save is shown explicitly and can be retried. Reopening the app resumes your saved formation. Exported files are separate copies; export again to update them.

The main window can be minimized independently of the sidebar. The default export folder is Documents/PvzFormationEditor; you can choose another folder in export settings.

Card selection defaults Fume-shrooms, Gloom-shrooms and Magnet-shrooms to an awake appearance; other sleepable mushrooms default to asleep. You can change the appearance. Saving, exporting and applying to the game always use the final selected sprite frame. Loading an existing formation never reapplies card defaults.

Loading and exporting

  1. Paste a formation code into the upper input; on Windows, you can also choose a read format beside Read from game.
  2. Load into editor opens the input. Paste and import reads and validates clipboard text before loading it; empty or invalid content leaves the current formation intact.
  3. The current code updates as you edit. The copy format has its own Toolkit/website selection.

Toolkit codes share standard plant layouts; website codes retain zombies and appearances. Encoding errors include a reason. Format is undoable.

Generate image preserves the game aspect ratio by default, with scale and background options. A preview opens near the click inside the toolbox, with Copy, Export and Close actions. Export background saves the scene background.

Reading and applying game formations

Windows only. Supports original Windows PvZ 1.0.0.1051, Survival Endless modes 11–15. Enter seed selection or a paused board before use.

  1. Choose a format beside Read from game. Toolkit reads plants; website format includes plants and zombies. The result fills the input.
  2. Load into editor opens it for editing. Reading alone leaves your editor document intact.
  3. Apply replaces the game layout. The main toolbar play button, Load / Export, archive/preset details and each item's More menu share this action.

Toolkit codes are for copying and sharing. Apply writes directly to the game, including supported zombie states. It supports six standard scenes, Imitaters, mushroom sleep, graves, ladders, rakes, cannon loading and other stable plant states. Loaded cannons are ready to fire; empty cannons start charging when play resumes.

Supports 21 zombie types and stable appearances, including carried objects, grounded balloons, submerged/surfaced snorkel zombies and eating. Dolphin atlas positions are converted to game coordinates and poses initialized while paused. Plant highlights initialize the original chew flash, then follow the game's updates. Writes are checked by reading back.

Custom six-row lawns and roofs are available for editing and image sharing; applying them shows the supported scene range. Plant-only applications retain existing zombies; formations containing zombies replace both layouts.

Apply offers an unchecked-by-default Clear zombies option. Lazy Layout also provides a standalone clear action that retains existing plants and sunlight. Formations containing zombies still replace them with the target layout. Archive details use mutually exclusive Toolkit/website choices and one Copy formation code button.

Your archives

Open Archive Library, to the left of Layout Presets in the sidebar. It contains the existing archive browser, game read/apply actions, and the batch-selection, export and deduplication controls at the top. Select all, clear the selection or export selected items after entering batch mode. Edits automatically update the same archive and preserve version history. Reopening restores the previous tabs. New blank tabs enter the archive after the first meaningful edit, rename or explicit save.

Bulk selection provides a select-all checkbox, partial selection and clear selection. Export selected archives or confirm their deletion, including history and related editor tabs. Startup leaves planting unarmed, and catalog height follows the actual card rows.

PC Endless save import (experimental) extracts plant layouts from game*_13.dat files while retaining the source file. Unsupported versions or contents are rejected.

Frequently asked questions

The game cannot be found, or reading fails.

Check the game version and enter a Survival Endless level. Run the game and editor with matching permissions. If the game runs as administrator, the editor needs matching privileges.

Why can’t I generate or apply this formation code?

Code encoding and game integration have separate limits. Follow the specific error shown in the app to remove conflicting or unsupported objects, then try again. Use full project JSON to retain complete editor properties.

How do I report a problem?

Join QQ group 425175276 or open a GitHub issue. Include the app version, game version, reproduction steps and, when useful, the formation code.

Website analytics and privacy

First-party analytics use Cloudflare Pages and D1 to measure page views, application download clicks and QQ group link clicks. Random visitor and session IDs are stored in your browser for deduplication. Only the referring hostname and a coarse country/region code are recorded. Raw IPs, URL query strings, formations and account information are not stored. Reports use Beijing time and retain up to 400 days. Do Not Track and Global Privacy Control are respected. Clearing site storage resets the identifiers. Download clicks do not indicate completed downloads; browser visitor IDs do not count actual people. Collection starts when enabled and cannot recover earlier visits. Analytics cover website page views and link clicks.
