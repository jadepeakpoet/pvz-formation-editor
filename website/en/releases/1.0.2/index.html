VERSION 1.0.2

v1.0.2

  • Extract plant appearances and hit masks on demand, sharing identical images.
  • Generate preset and archive previews on demand with a 4 MiB memory cache that protects visible previews. Thumbnail disk caching and compression are disabled by default.
  • Remove pre-cut plant images and 363 bundled thumbnails while retaining preset names, filters and layouts.
  • Use a smaller in-app logo and retain the original artwork for icon generation and the large website logo.
  • Coalesce duplicate appearance-loading requests and improve cache lookups.

macOS downloads: Apple Silicon arm64 · Intel x64. Requires macOS 12.0+. Packages are ad-hoc signed without Developer ID signing or Apple notarization; see first-launch instructions. Live-game integration remains Windows-only.

Existing archives, autosave, workspace restoration, formation codes and game integration retain their formats and behavior.
