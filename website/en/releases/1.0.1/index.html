WINDOWS / 1.0.1

v1.0.1

Windows 10 / 11 x64 portable edition.

  • Selected mushroom appearances determine sleep; cannon and supported stable plant states are preserved.
  • Live-game formations support stable zombie appearances, carried objects, water states and eating, with corrected dolphin coordinates and paused poses.
  • Paste and import validates clipboard codes. Read and copy have independent Toolkit/website choices.
  • Image generation preserves the original aspect ratio and opens a toolbox preview for copying or exporting.
  • Map changes retain plants by default. Minimized toolboxes restore from their toolbar button. Deduplication feedback stays in the archive window.
  • On-demand shared artwork, 363 bundled thumbnails, bounded image caches, autosave and workspace restoration.

Read the user guide · GitHub Releases

Apply formation offers an unchecked-by-default Clear zombies option. Lazy Layout also provides a standalone clear action that retains existing plants and sunlight. Formations containing zombies still replace them with the target layout. Archive details use mutually exclusive Toolkit/website choices and one Copy formation code button.

Bulk selection provides a select-all checkbox, partial selection and clear selection. Export selected archives or confirm their deletion, including history and related editor tabs. Startup leaves planting unarmed, and catalog height follows the actual card rows.
