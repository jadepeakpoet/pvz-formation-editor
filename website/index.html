落植为棋，布阵成道

把阵型的构思、编辑和存档整理的过程，放进本地布阵器。主画面专注阵图，“存档仓库”与布阵工具在侧窗的同一排页签中随时切换。

下载 Windows 绿色版 ↓开始使用 →

Windows 10 / 11 · x64 · 解压后运行，无需安装
查看下载校验值 · v1.0.1 更新说明

从一张阵图开始
01 / 编辑

两扇窗口，各司其职

在主画面摆放植物、调整场景，用工具箱完成布局、镜像和图片导出。

02 / 存档

阵型留在本地

使用存档库整理阵型，按需批量选择、导出与去重，管理自己的布阵记录。

03 / 游戏

从阵图走进关卡

读取运行中游戏的阵型码，或将当前阵型应用到游戏。支持范围与操作要求请先查看文档。

解压，打开，开始布阵。

  1. 下载绿色包并完整解压，保留程序旁的 DLL 和 data 文件夹。
  2. 运行 pvz_formation_editor.exe，选择场景并编辑阵型。
  3. 在“载入导出”中复制阵型码、导出图片，或读取游戏中的阵型。
