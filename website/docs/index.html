开始你的本地布阵

基于 Flutter Widget / Canvas 的本地布阵器，提供阵型编辑、自动存档、363 个内置名阵、阵型码交换、图片导出及 Windows 游戏读写。

下载与运行 · 编辑阵型 · 载入导出 · 游戏读写 · 存档库 · 常见问题

平台与验证范围

Windows 为主要平台，面向 Windows 10 / 11 x64；Release 构建、双窗口交互、自动存档、导入导出及真实 1051 游戏读写已验证。游戏阵型读取、应用和游戏存档接入为 Windows 专属功能。

项目提供 Windows、macOS、Linux、Android、iOS 工程。macOS 已有构建与桌面交互验证；Linux、Android、iOS 待构建与设备验证。当前发行包面向 Windows。

下载与运行

  1. 下载 Windows x64 绿色包，解压到可写目录。
  2. 打开 pvz_formation_editor.exe。不要只从压缩包中单独拖出 EXE，程序需要同目录的运行库及 data 文件夹。
  3. 主画面与侧边窗口配合使用；工具箱顶部的“存档仓库”页签可以打开存档页面，主画面顶部的“关于”提供文档与项目链接。

支持 Windows 10 / 11 x64。绿色包无需安装，但本地数据保存在用户应用数据目录；移动程序目录不会自动带走存档。迁移前请从存档库导出需要保留的数据。

编辑阵型

选择场景、植物与摆放工具，在阵图中完成布局。工具箱提供懒人布局、显示设置、镜像与导出选项。“显示土壤水花”默认关闭，可按需要开启。修改可以使用撤销与重做。编辑自动保存到本地存档，主画面顶部显示保存状态；保存失败会明确提示并可点击重试。重新启动应用可继续上次的阵型。导出的文件是独立副本，需要重新导出才能更新该副本。

选卡默认将大喷菇、忧郁蘑菇、磁力菇设为唤醒外观，其他可睡眠蘑菇默认睡眠。用户可以继续切换外观，保存、导出和应用到游戏时均以最终外观帧为准，载入既有阵型不会重新应用选卡默认值。

载入与导出

  1. 进入“载入导出”，将 PvZ Toolkit 或网页布阵器阵型码粘贴到上方输入框。
  2. 点击“载入布阵器”，把输入的阵型载入当前编辑画面。
  3. 下方“当前阵型码”会随编辑实时更新，可直接复制，或点击“应用到游戏”。

无法编码的内容会显示原因；“一键格式化”会清理冲突和不支持的内容，操作可撤销。图片导出可以调整倍率和背景；“导出底图”保存当前场景背景。

读取和应用游戏阵型

此功能用于 Windows 原版 1.0.0.1051，生存无尽关卡（模式 11–15）。请先运行游戏并进入实际关卡；其他游戏版本和改版未保证兼容。

  1. 在“载入导出”输入框上方点击“从游戏获取”。读取结果会填入输入框，供你查看和复制。
  2. 需要编辑时再点击“载入布阵器”；单纯读取不会替换当前正在编辑的阵图。
  3. 编辑完成后，点击下方“应用到游戏”，用当前阵型替换游戏布阵；游戏当前阳光数保持不变。

支持常规植物、模仿者、墓碑、梯子、钉耙、六类场景、跨场景布阵及白天蘑菇状态。最终外观决定睡眠、玉米炮装填等可持久状态；有弹炮进入可发射状态，空炮在恢复运行后立即开始装填。界面会提示所选对象和外观的适用范围。应用前可读取并复制重要布局。

我的存档

从工具箱顶部、“懒人布局”左侧进入“存档仓库”，可以打开阵型、接入游戏读取与应用操作，并使用顶部的批量选择、导出和去重功能。批量选择后可全选、清空选择或导出所选内容。编辑自动保存到“我的存档”，后续修改更新同一个存档并保留历史版本。重新启动恢复上次打开的标签；新建空白页在首次有效修改、重命名或主动保存后入库。

常见问题

提示找不到游戏或读取失败？

确认运行的是受支持的游戏版本，且已经进入生存无尽关卡。游戏与布阵器应使用相同权限运行；若游戏以管理员身份启动，布阵器也需要对应权限。

为什么阵型码无法生成或无法应用？

阵型码和游戏写入各有支持范围。请根据界面显示的具体错误清理冲突或不支持的对象，再重试。需要保留完整编辑属性时，可使用完整项目 JSON。

官网访问统计与隐私

官网使用 Cloudflare Pages 和 D1 自建第一方统计后台，采集页面浏览、Windows 包下载点击及加群点击。浏览器本地保存随机访客标识与会话标识，用于去重；来源仅保留域名，地区仅保留国家或地区代码，不保存原始 IP、网址查询参数、阵型内容或账号信息。数据按北京时间汇总，保留最近 400 天。尊重浏览器 Do Not Track 和 Global Privacy Control 设置；也可通过清除本站存储重置标识。下载点击不等于下载完成，访客数不等于真实人数。统计从接入之日起开始，不补记此前访问。统计范围为官网页面访问与链接点击。
