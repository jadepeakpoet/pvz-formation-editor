WINDOWS / 1.0.1

v1.0.1 更新说明

Windows 10 / 11 x64 绿色版。

  • 蘑菇按最终外观保存睡眠状态，玉米炮装填及支持的植物稳定状态同步到游戏。
  • 游戏布阵支持僵尸稳定外观、携带物、潜水/出水和啃食，修正海豚位置及暂停时的姿态。
  • 新增校验剪贴板内容的“粘贴导入”；读取与复制分别选择 Toolkit 或网页码。
  • 生成图片默认保持原比例，在工具箱弹窗中预览、复制和导出。
  • 切换地图默认保留植物；工具箱最小化后点击入口恢复；去重反馈留在存档库。
  • 按需共享图片、363 张包内缩略图、有容量预算的缓存、自动保存及上次标签页恢复。
