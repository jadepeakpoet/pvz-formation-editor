**落植为棋，布阵成道。** 基于 **Flutter Widget / Canvas** 的跨平台本地布阵器，以 **Windows** 为主要发布和验证平台，集阵图编辑、本地存档、阵型码交换、图片导出及 Windows 游戏阵型读写于一体。

## 主要功能

- **阵图编辑**：26 种地图，植物、僵尸与场地物品，多图层摆放、外观帧选择、翻转、批量放置和铲除、自动补底座、撤销与重做。
- **选卡与布局**：图鉴选卡、模仿者选卡、十格卡槽，363 个完整名阵及局部布局，按场地、炮数和名称查找阵型。
- **双窗口工作区**：主画面编辑阵图，侧窗集中提供存档仓库、懒人布局、图鉴选卡、镜像窗口、载入导出和选项设置；支持最多三个只读镜像快照。
- **本地存档**：自动保存、重命名、备注和标签、搜索筛选、批量导入导出、去重、历史版本查看与恢复。
- **标签页恢复**：保存上次打开的全部阵型页、选中标签和文件关联，重启后继续编辑；首次使用或上次关闭全部页面时打开空白页。
- **阵型码与文件**：读写 PvZ Toolkit 阵型码、网页布阵器阵型码、完整项目 JSON 和存档集合，提供原文件保存、覆盖前备份与恢复。
- **图片分享**：PNG 图片导出、背景导出、图片复制、导出倍率与背景设置；默认保持游戏原比例，在工具箱弹窗中预览、复制和导出。默认导出目录为文稿目录下的 `PvzFormationEditor`。
- **Windows 游戏接入**：识别运行中的原版游戏，读取和应用实际阵型，支持六种标准场地、模仿者、蘑菇睡眠、玉米炮装填及多类植物状态，提供游戏存档文件读取与备份入口。
- **图片资源管理**：植物帧按需加载、相同图片复用，363 张 256×192 缩略图随包提供，合计约 7.49 MiB；列表使用有容量预算的解码缓存，自定义缩略图生成后保存到本地。
- **中英文界面**：应用与官网提供简体中文和 English，语言选择会保留。

## Windows 快速开始

1. 下载 [Windows 绿色包](https://xmpvz.pages.dev/)，完整解压。
2. 保留同目录 DLL 和 `data` 文件夹，运行 `pvz_formation_editor.exe`。目标系统为 Windows 10 / Windows 11 x64，包内包含本地 MSVC 运行库。
3. 在侧窗选择地图、植物与工具，也可从“存档仓库”打开名阵，直接开始编辑。
4. 查看顶部自动保存状态；分享时复制阵型码或导出项目、存档集合和 PNG。

## 自动保存与本地数据

“我的存档”统一保存可编辑阵型。名阵打开到编辑标签后立即入库；新建空白页在首次有效编辑、重命名或显式保存后创建存档。后续修改持续更新同一个存档，并保留历史版本；另存为可建立独立副本。

切换标签、离开编辑页和正常退出时刷新保存队列。顶部显示自动保存状态，写入异常可重试。重启恢复上次工作区，撤销与重做用于当前打开的编辑会话。

数据库为用户应用支持目录内的 `formations.sqlite`。迁移设备可导出 `*.pvzlib.json` 存档集合；完整数据库备份在正常退出后进行，保留同名 journal/WAL/SHM 配套文件。绿色包与用户数据分开保存。

## Windows 实际游戏读写

适配 **Windows 原版 PvZ 1.0.0.1051，生存无尽模式 11–15**。

- **从游戏获取**：在“载入导出”的输入框上方选择 PvZ Toolkit 或网页格式，再读取当前游戏阵型。结果填入输入框，点击“载入布阵器”进入编辑。
- **含僵尸布局**：读取时选择网页格式可同时获取植物与僵尸，支持 21 种僵尸的种类、位置及 103 个稳定外观组合，包括无盒小丑、气球落地、潜水与出水、丢失报纸或工具等状态。读取与应用会核对实际动画及携带物图层。
- **应用阵型**：主区域“卡槽选卡”旁的 ▶ 按钮使用当前阵图替换游戏布阵。载入导出、存档/名阵详情及列表“更多”菜单提供相同操作。
- **阵型码交换**：支持复制 PvZ Toolkit 码与网页阵型码，也可校验剪贴板内容后直接粘贴导入。
- **外观对应状态**：选卡默认让大喷菇、忧郁蘑菇和磁力菇显示唤醒外观；用户可继续修改，输出和写入以最终帧为准。有弹玉米炮直接可发射，空炮冷却归零后开始装填。土豆雷、阳光菇、仙人掌及部分植物受损外观有对应游戏状态。
- **海豚布阵**：按所选外观区分游泳与啃食，转换原图与游戏的不同横向锚点；暂停时初始化姿态，植物高亮对应原版受啃食闪光。
- **游戏存档接入**：浏览游戏存档目录，读取支持的无尽存档布阵，并备份或另存存档文件。

游戏读写已在真实 1051 进程中验证，应用后会重新读取并比较植物组成和相关状态。操作说明与格式范围见 [Windows 游戏接入](docs/game-integration/windows-1051.md)。

游戏应用支持六种标准场地；自定义六行草地、六行屋顶等场地可在编辑器中绘制，应用时会提示支持范围。

## 文件格式

| 格式 | 适合用途 |
| --- | --- |
| PvZ Toolkit 阵型码 | 分享六种标准场地的格位布阵、模仿者和蘑菇睡眠状态 |
| 网页布阵器阵型码 | 保存兼容对象的格位、外观帧和效果字段，与原网页交换 |
| `*.pvzf.json` / `PVZF1:` | 保存完整编辑项目，包括外观、卡槽、显示设置等 |
| `*.pvzlib.json` | 批量迁移当前阵型、名称、备注和标签，导入时按内容去重 |
| PNG | 分享阵图或地图背景图片 |

各格式按其可表达字段保存；需要完整保留工作内容时选择完整项目。存档集合保存当前版本，历史版本随本地数据库保留。文件导入先验证完整内容，再写入数据；上限为 8 MiB、5,000 对象。

## Flutter 开发与构建

项目名为 `pvz_formation_editor`。界面使用 Flutter Widget，阵图使用 Canvas 绘制，本地存档使用 SQLite。构建基线为 Flutter **3.47.8 stable** / Dart **3.13.7**，依赖版本记录在 `pubspec.lock`。

```sh
flutter pub get
flutter run -d windows
flutter build windows --release
```

Windows 使用 Visual Studio C++ 桌面工具链与 Windows SDK；其他平台在对应宿主上构建。完整说明见 [开发文档](docs/development.md)、[macOS 构建](docs/macos-run.md) 和 [官网部署](website/README.md)。
