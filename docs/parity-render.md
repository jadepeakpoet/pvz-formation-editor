# Real engine rendering and screenshot comparison

`tool/parity_render.dart` renders the actual `BoardPainter` through Flutter's engine. It generates 800×600 PNGs for 26 original maps, every supported object/frame, the seven original effects on every object (the fifth effect is named 阴影 in the protocol and 我是僵尸 in the UI), three flips on every object, and all 363 original formations. It also reads `docs/parity-cases.json` (`cases` array) and overrides generated cases with the same ID. `formation` is a `Formation.toJson()` document; `presetString` is an original site string. `kind: full|toolbox|window` cases are captured by the UI runner, not the board renderer.

Artifacts default to `/tmp/pvz-parity/flutter/ID.png` and `/tmp/pvz-parity/render-results.json`. Set `PVZ_PARITY_DIR`, `PVZ_PARITY_MANIFEST`, or `PVZ_PARITY_FILTER` (regular expression) for focused runs. A successful render records document state but does not establish reference equivalence.

Use the installed SDK/engine path for another host. The asset bundle must be built before rendering. The comparison script needs Pillow. On this host an existing environment is available at `/Users/developer/coding/python/VobSub-ML-OCR/env/bin/python`.

The comparator reads reference `reference/ID.png` (also `.jpg`/`.jpeg`) or a manifest `reference` path. Manifest `referenceClip` and `flutterClip` are `{x,y,width,height}` or `[x,y,width,height]`. These explicit crops support full-window and toolbox comparisons. It rejects differing dimensions and never rescales or aligns images. It decodes embedded ICC profiles into the common sRGB comparison space; this is necessary because browser JPEG captures on this host use Display P3 while Flutter PNGs use sRGB. Raw encoded-channel MAE and different-pixel ratio are retained alongside color-managed metrics. No fitted color correction is applied.

`diff/report.json` reports RGBA MAE in the common sRGB space, raw encoded-channel MAE, exact different-pixel ratio, max channel error, and ratio over fixed channel threshold 8. The threshold is descriptive only: exact success requires every pixel to match. JPEG references introduce compression differences, so a nonzero result must be inspected; it must never be relabeled exact. For each comparable case the script saves an absolute RGB difference, alpha difference, amplified red heat map and side-by-side image. Missing references, missing Flutter captures, render failures, dimension mismatches, and genuine pixel differences remain separate failures. It returns nonzero unless every case is exact.

Current limitation: board frame/effect combinations prove renderability only until corresponding original-site reference captures are available. Full interaction coverage and screenshots require the UI runner and original browser action cases.

For existing UI-runner captures, repeat `--ui-root DIRECTORY`. The comparator maps `toolbox.preset.formation.N`, `toolbox.preset.cob.N`, `toolbox.preset.gloom.N`, tab names encoded as URI components, and window style captures to their actual `*-toolbox.png` files. It chooses the most recent matching capture and keeps its original dimensions. Use `--kind toolbox` for a separate UI pass, `--kind board` for a board pass, and `--output-dir DIRECTORY` to keep independent reports. A focused pass reports only that requested scope. Invalid source scenarios can be marked `invalidReference: true` with a `reason`; they remain failures, recorded separately from product differences.

The renderer accepts `presetIndex` for full formations and `partialFamily: cob|gloom` plus `presetIndex` for partial layouts on the pool map. Unknown board inputs fail explicitly. Single-object cases record their actual painted bounds. The comparator additionally writes object-region metrics and difference images while preserving the full-frame metrics, so background compression error cannot conceal a wrong effect or sprite position.

The original protocol stores opacity separately from its color mask. The renderer uses `Piece.opacity` once for the complete sprite and its attached parts; it does not multiply it a second time merely because the effect list includes 半透明. Imitation atlases use HSL lightness (half the minimum plus maximum RGB channels) and each original template's `light` attribute. This is nonlinear and is precomputed into RGBA atlases. Other measured channels use the original UI reference colors; JPEG reference error and unresolved shadow edge differences remain visible in reports.

`GrowthEffect(row:, col:, frame:, water:)` optionally supplies one of the six original 61×34 growth tiles to `BoardPainter.growthEffects`. Water defaults to the map's water rows. The origin is `cellCenter + (-30,17.5)` (ground position minus 30 horizontally and 20 vertically), matched independently to all four visible tiles in the captured two-cannon pool birth frame. An empty list is the default, and the soil display toggle hides explicit frames. `test/renderer_growth_smoke.dart` verifies all twelve dirt/water atlas tiles and the guard using the real engine. The editor must supply the lifecycle; source frame duration and complete animated acceptance remain pending. Static screenshot references disable birth effects before applying formations to avoid testing arbitrary transient frames.

Source roof DOM measurements justify the five-pixel lift for plants/shells over pots while leaving pots and props unchanged; roof mowers use one additional 20-pixel slope step because they occupy source column zero. Drawing and hit precedence follow source row ascending / column descending within the same layer. `test/renderer_positioned_smoke.dart` covers recorded roof CSS tops, positioned ladders, and `exportPng(pokerWidth: true)` producing 917×600 instead of the default 800×600.

A later primary-source read resolved birth timing: frames start at 0/100/200/300/400/500 ms and remove at 650 ms. Visual soil visibility does not gate planting sound. Lifecycle integration is a separate main/editor lane; the renderer's atlas tests alone do not prove that integration. Source seed-card coordinates and the new chooser have separate focused evidence in `docs/seed-chooser.md`.
