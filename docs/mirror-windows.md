# 镜像与工具箱窗体实现记录（2026-10-20）

本轮将镜像从工具箱内嵌列表改为桌面浮窗；最多三个独立文档快照。每个镜像支持标题拖动、关闭、1 / 3/4 / 2/3 / 1/2 / 1.5 / 2 倍显示、背景开关和单独 PNG 导出。大倍率在窗口内滚动查看完整画布，不裁掉输出 PNG。背景仅控制地图底图，沿用原渲染器的卡槽和推车显示设置。

工具箱也可通过标题拖动。顶部“窗口复位”恢复工具箱与所有镜像的位置；标题位置限制在桌面可达范围。窗体限于应用内部，并非操作系统独立窗口；尚未逐像素对齐原站三种窗口皮肤，也未实现原站扑克等宽。
