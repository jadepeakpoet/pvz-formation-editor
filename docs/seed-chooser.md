# Original seed chooser, focused acceptance

`OriginalSeedChooser` in `lib/editor/seed_chooser.dart` is a standalone widget with `document`, `onChanged`, `onClose`, and optional `readOnly`. It changes only seed-slot and imitater-index fields. The host positions it over the PVZ board; ROCK invokes only the close callback.

The toolbox's first “卡槽选卡” control directly toggles this overlay, independently of the active toolbox content tab. It has no intermediate toolbox page, separate open button or duplicate selected-card list. Main-window state broadcasts overlay visibility to the native toolbox replica; the replica requests an authoritative toggle from the main engine. ROCK clears the first control's active appearance through that same state.

Primary evidence: [original HTML](http://jspvz.com/ArrayDesign/) and its public [main.js](http://jspvz.com/ArrayDesign/main.js). The main chooser enumerates original IDs 0–47; the imitater chooser enumerates 0–39. Normal and imitater versions of the same plant can coexist; the total limit is ten and the imitater limit is one. Removing preceding cards shifts the imitater slot index. Source `ClickTenCard`, `ClickImiCard`, `ViewImitater`, and `ClickTab` were consulted for behavior, not copied into Dart.

The main panel now matches measured source geometry: 465×513 at x13/y113 inside the PVZ window, first normal card at panel x25.25/y36, six 70px rows, and the ROCK button at x157.5/y462 (150×35). The imitater side attachment is at x458/y415 (66×93), with its card at x463/y427 (50×70). Selected lower cards use grayscale rather than reduced opacity. Both normal and gray selections may be returned by clicking their actual top-bank cards; remaining indices shift, and returning the imitater re-enables the side entry. The side entry itself does not remove an already-selected imitater.

The imitater dialog opens over the main panel instead of replacing it: frame offset x148/y−75, 505×580; gray grid x44/y116 with 1px card margins and forty base plants. The component reserves 655×588 hit-test space, including 75px above the main panel, so the rightmost dialog cards and side attachment remain clickable. Eight static dialog border PNGs were copied from the already-extracted local game reference. The frame uses the web DOM's geometry with those local static decorations; this is not a claim of whole-page pixel identity. A small close control is retained for returning from the gray chooser. Read-only mode prevents changes and still permits closing.

Six missing 50×70 gray-card files were recovered from their original public URLs under `http://jspvz.com/ArrayDesign/image/Card/`: `Cornpult_i.png`, `Garlic_i.png`, `Coffeebean_i.png`, `Marigold_i.png`, `Melonpult_i.png`, `Umbrellaleaf_i.png`. Each downloaded file's PNG signature and dimensions were checked, and the asset manifest updated. All forty original base plants now have source gray art. A grayscale normal-card fallback remains for unavailable gray assets; it is resilience, not a substitute claimed identical to source art.

Source selected-card placement comes from HTML `dTenCards` left88/top8 plus each image's left margin1 and width50: first x89, subsequent stride51. `BoardPainter.seedSlotBounds` now reflects this. Its existing source-card pixel test checks two normal/gray pea cards (7000 opaque pixels within ±1 RGBA), explicit x89/51 spacing and dimensions, then deliberately removes the gray asset to verify the fallback (RGB tolerance2 for matrix rounding). Real-engine run: `/tmp/pvz-seed-renderer-new.log`; images `/tmp/pvz-parity-seed-cards.png`, `/tmp/pvz-parity-seed-fallback.png`.
