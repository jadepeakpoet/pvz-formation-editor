# 种植覆盖与叠加

布阵器采用快速布局的编辑规则，支持直接摆放升级植物与跨地形设计。

- 普通植物替换同格主植物，底座、外壳和咖啡豆分别保留独立槽位。
- 荷叶与花盆共用底座槽；补底座保留主植物、南瓜和咖啡豆。
- 南瓜使用外壳槽，咖啡豆使用上层槽，同类对象互相替换。
- 玉米炮作为整体占两格。普通植物与任一格冲突时替换整炮；底座可单独保留。摆放新炮清理覆盖范围内的冲突主植物、南瓜、咖啡豆及梯子。
- 猫尾草、缠绕水草和海蘑菇在水面直接摆放；为其添加外壳时保留原有底座关系。
- 自动补底座与摆放合并为一次可撤销操作。重复点击同种植物可循环可用状态。

交互参考 [jspvz 网页布阵器](http://jspvz.com/ArrayDesign/)；槽位关系参考 [PvZ-Portable](https://github.com/wszqkzqk/PvZ-Portable)。游戏素材说明见 [资源](assets.md)。
