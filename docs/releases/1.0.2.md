# v1.0.2

- Reduced bundled artwork by keeping the original sprite sheets and extracting only the appearances in use. Identical frames share cached images; hit masks are generated on demand.
- Generate preset and archive thumbnails when displayed, using a bounded 4 MiB memory cache that protects visible previews. Thumbnail disk caching and compression are disabled by default.
- Removed 363 bundled thumbnail images and pre-cut sprite images from the application package. Preset names, filtering and layouts remain available through lightweight metadata.
- Reduced the in-app logo image size while retaining the original artwork for icon generation.
- Coalesced repeated appearance-loading requests and improved image-cache lookups.

Existing archives, automatic saving, workspace restoration, formation codes and game integration retain their existing formats and behavior.
