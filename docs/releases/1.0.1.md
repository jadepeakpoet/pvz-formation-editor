# v1.0.1 · Windows

本次发布 Windows 10 / 11 x64 绿色版，解压后运行 `pvz_formation_editor.exe`，保留同目录的 DLL 和 `data` 文件夹。

- 修复阵图显示蘑菇睡眠、应用到游戏却唤醒的问题。选卡默认将大喷菇、忧郁蘑菇和磁力菇设为唤醒外观；用户修改后，保存、网页阵型码和游戏读写以最终外观帧为准，载入已有阵型不会重新应用默认值。
- 修复有弹玉米炮应用后先显示空炮、再装填的问题。有弹外观直接进入可发射状态并同步动画；空炮外观初始化为冷却结束，恢复运行后立即开始装填。
- 按所选外观读写土豆雷出土、阳光菇大小、仙人掌高矮，以及坚果、高坚果、大蒜、地刺王的受损程度。瞬时发射动作不作为可持久的初始布阵状态。
- 保留其他植物的编辑外观，完整项目及网页阵型码可保存所选帧。PvZ Toolkit 阵型码本身不保存玉米炮装填、耐久等全部运行状态；需要保留这些状态时使用完整项目或网页阵型码，再直接应用文档到游戏。
- 包含按需加载和共享植物帧、包内 363 张缩略图、有容量预算的图片缓存及上次标签页恢复。
- 官网增加独立的访问统计后台；桌面应用未加入联网使用统计，密码、密钥和访客数据不包含在源码及发布包中。

验证：44 项模型/编解码测试、Flutter 静态分析、实际编辑界面与 GameBridge 测试通过。Windows 原版 1.0.0.1051 已实测十种蘑菇、八类稳定植物状态、玉米炮的内部状态和动画帧范围，应用后读取一致，测试后恢复原阵型。

官网：https://xmpvz.pages.dev · 文档：https://xmpvz.pages.dev/docs/ · 交流 QQ 群：425175276。

游戏接入支持原版 Windows PvZ 1.0.0.1051 生存无尽模式 11–15。其他平台本次仅提供源码，没有对应发布包。
