# v1.0.1 ? Windows

Download the Windows x64 portable ZIP below, extract it, and run `pvz_formation_editor.exe`. Keep the DLL files and the `data` folder alongside the executable.

## What's new

- Plant appearance and game state now stay consistent when saving, importing, exporting, and applying formations. Mushroom sleep states follow the final selected appearance; Fume-shroom, Gloom-shroom, and Magnet-shroom default to awake when selected.
- Loaded Cob Cannons are immediately ready to fire. Empty cannons start loading when gameplay resumes. Potato Mine readiness, Sun-shroom size, Cactus height, and supported plant damage states also follow the selected appearance.
- Game integration supports stable appearances and states for 21 zombie types, including carried equipment, balloon loss, diving/surfacing, and eating. Dolphin position, eating pose, and the attacked Pumpkin highlight have been corrected.
- Apply formations from the main window, Transfer panel, archive details, or list menu. Optionally clear existing zombies; the checkbox is off by default. Quick also provides a separate clear-zombies action.
- Paste Import validates clipboard content before loading. Copying formation codes offers PvZ Toolkit and web editor formats. Toolkit codes retain their existing format; use a full project or web editor code to preserve additional appearance details, then apply the formation directly to the game.
- Improved automatic saving, archive controls, select-all and batch deletion, and restoration of previously open tabs. Startup no longer selects a plant automatically.
- Reduced image-loading overhead with on-demand loading, shared plant frames, bounded caches, and 363 bundled thumbnails.
- Exported images preserve the game's aspect ratio. Image previews open near the action in the toolbox, with copy and export controls.
- Changing maps keeps plants by default. Opening a minimized toolbox restores it. Dialogs stay with the window that initiated them.
- Fixed restoring window positions on Windows while preserving window size, visibility, and minimized state.
- Improved compatibility when importing existing PC Endless saves.
- Fixed the Cob Cannon support actions: remove the Flower Pot or Lily Pad beneath the cannon's right cell on the applicable terrain, keeping the left support and cannon. Undo and redo are supported.
- Improved Chinese and English interface text and help.

- 按所选外观读写土豆雷出土、阳光菇大小、仙人掌高矮，以及坚果、高坚果、大蒜、地刺王的受损程度。瞬时发射动作不作为可持久的初始布阵状态。

- 包含按需加载和共享植物帧、包内 363 张缩略图、有容量预算的图片缓存及上次标签页恢复。
- 完善中英文帮助、自动存档说明和平台信息。
- Windows 游戏布阵支持 21 种僵尸的稳定外观与状态，包括携带物、气球落地、潜水/出水和啃食；修正“饲养海豚”的横向位置及啃食帧，暂停时同步初始化海豚姿态与南瓜受啃食高亮。
- 主画面、载入导出、存档详情及列表“更多”统一提供“应用阵型”；读取和复制可分别选择 PvZ Toolkit 码或网页布阵器码。
- 新增“粘贴导入”：读取剪贴板，校验通过后载入；无效内容保留当前阵型。
- 应用阵型可勾选“清除场上僵尸”，默认不勾选；懒人布局增加一键清除僵尸，保留现有植物与阳光。包含僵尸的阵型仍按目标布局替换僵尸。
- 存档详情先选择 PvZ Toolkit 码或网页布阵器码，再统一复制；复制与应用按钮增加可见边框、点击面积和间距。
- 存档列表提供全选/半选复选框及确认后批量删除；删除同步移除已打开的相关标签和历史导航，避免自动保存重建已删除存档。启动时不默认选中植物。
- 图片默认保持游戏原比例；生成后在工具箱内靠近点击位置弹出预览，提供复制和导出，关闭后释放本次预览缓存。
- 切换地图默认保留植物；工具箱最小化后再次点击入口会恢复显示；存档去重弹窗留在存档库，文件选择框跟随触发操作的窗口。
- 修复 Windows“恢复窗口初始位置”失败：主窗口与侧窗回到当前屏幕可见区域，保留窗口尺寸、隐藏及最小化状态。
- 修复 PC 无尽存档导入对掉落物记录尺寸及空闲记录标记的识别，兼容实际旧存档，清理内部验证进度提示。
- 修复“碾花盆、炸荷叶”：按陆地／水路移除玉米炮右侧格子的底座，保留左侧底座和玉米炮，支持撤销与重做。

游戏接入覆盖白天、黑夜、泳池、浓雾、屋顶、月夜屋顶六种标准场地；编辑器中的自定义六行草地和六行屋顶用于阵图编辑，应用时会提示场地范围。
