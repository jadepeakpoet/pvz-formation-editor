# 我的存档

我的存档统一管理可编辑阵型。名阵打开为编辑页后自动入库；新建空白页在首次有效编辑、重命名或显式保存后创建存档。后续修改、撤销、重做和清空都保存到同一个存档。

## 管理与恢复

存档使用稳定 ID，名称、备注、标签和阵图分别保留。搜索可以与场地/炮数筛选组合，批量选择可跨筛选保留。列表“更多”和详情提供编辑、复制阵型码、导出、历史版本及 Windows 游戏应用入口。

历史版本可预览和恢复，恢复前的内容继续保留。存档去重只合并内容及相关元数据一致的条目，保留历史；正在打开的副本会受到保护。

## 导入导出

单个阵型可导出 Toolkit 码、网页码和完整项目 JSON；`*.pvzlib.json` 保存一组当前阵型及名称、备注和标签。导入时按阵型内容比较，重复内容跳过，同名不同内容自动调整名称。

导入先校验全部文件，成功后统一写入并报告数量。文件上限 8 MiB，阵图对象上限 5,000。默认目录为文稿目录下的 `PvzFormationEditor`，可在设置或保存面板调整。

## 工作区与数据

重启恢复上次打开的所有标签和所选页；正常退出会等待保存队列。SQLite 文件为用户应用支持目录下的 `formations.sqlite`。迁移当前存档可导出集合，完整历史随数据库备份保留。

自动保存采用最后保存的编辑内容作为当前版本；覆盖前将数据库中的上一版本完整保留到历史。旧编辑基准或其他窗口更新不会阻止自动保存。备注、标签和收藏等存档元数据随记录保留。
