# 存档与分享

未修改的新建空白页暂不入库，首次实际编辑、重命名或明确点击“保存”后，在“我的存档”创建带唯一名称的文档，例如“新建阵型”“新建阵型（2）”。没有单独的草稿分类。已有存档的编辑、撤销、恢复和重命名自动保存，清空也继续保存；“保存”等待当前修改落盘，“另存为”创建独立存档。同一个存档复用已有标签页。启动恢复上次实际打开的存档，不按最近更新时间猜测；不恢复上次进程的撤销栈或所有标签页。

工具栏以弯曲箭头标识“撤销 / 恢复”，恢复指重新执行刚撤销的操作。Windows/Linux 快捷键为 Ctrl+Z、Ctrl+Y、Ctrl+S；macOS 为 ⌘Z、⌘Y、⌘S，恢复也支持 ⇧⌘Z。按钮悬停提示显示快捷键，文本输入框内保留文本编辑快捷键。

个人存档菜单可重命名、查看历史并原位回退。回退前的内容也保留为历史版本。旧版草稿在数据库升级时迁入个人存档，保留原有个人存档及其历史，不用旧草稿覆盖它们。

预制名阵原件不可修改。可以直接在当前或新标签页使用模板、加入个人存档、收藏、预览、复制 Toolkit 码、导出以及复制或导出完整阵图图片。图片为 1600×1200 PNG。

个人存档可单个导出，也可批量选择或导出全部。筛选后“全选当前结果”仅添加当前结果；原来选中的筛选外项目仍保留，并明确提示数量。

单个阵型默认使用 PvZ Toolkit 格式，也可选择原网页格式或完整项目 JSON。批量使用 `.pvzlib.json`，保存当前阵图、名称、备注、标签及收藏信息，并在可表达时附带 Toolkit 码。批量文件不包含历史版本。文件上限 8 MiB，超过时请分批导出。

导入先完整验证文件，再比较阵型内容（忽略导入时重新生成的本地对象 ID）：与已有存档或同批前项完全相同的阵型跳过（不依赖名称）；同名、内容不同的条目追加“（2）”等后缀。不会用导入条目覆盖已有存档。完成后报告导入、跳过和重命名数量。

导出初始位置为系统文稿目录；保存面板允许修改位置，成功导出后记住目录。存档库设置可修改默认目录或恢复系统默认。设置写入失败不会把已经成功写出的文件误报为导出失败。

macOS 图片剪贴板使用 PNG 和 TIFF。Windows 使用系统图片剪贴板，Linux 使用 wl-copy 或 xclip；后两者尚未在本轮实际平台验证。macOS 导出目录持久化、图片渲染和系统剪贴板已做实际验证；系统保存/目录选择面板的完整人工点选尚未验收。
