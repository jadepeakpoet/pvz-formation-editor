# 文档、存档与编辑历史

## 数据职责

| 数据 | 用途 | 保存方式 |
| --- | --- | --- |
| 阵型文档 | 地图、对象、外观、卡槽与显示设置 | 完整项目或存档文档 |
| 我的存档 | 当前可编辑内容、名称、备注和标签 | 自动保存到 SQLite |
| 历史版本 | 查看和恢复较早内容 | 存档更新时保留 |
| 工作区 | 打开的标签、选中页、文件关联 | 启动时恢复 |
| 撤销/重做 | 当前标签的编辑操作顺序 | 编辑会话内保留 |

## 自动保存

名阵在编辑页打开时保存为可编辑存档。新建空白页首次有效编辑、重命名或显式保存后入库。修改按存档 ID 串行提交，切换标签和正常退出刷新队列，顶部显示实际保存状态。

保存失败时保留当前工作并提供重试。另存为生成独立存档；打开同一存档可复用已有标签。旧数据通过数据库版本迁移兼容。

## 编辑与恢复

连续拖放和批量操作分别组成一次可撤销命令。撤销/重做同步自动保存。每个标签的浏览历史保留阵型切换、名称和文件关联；重新启动恢复最后成功保存的工作区。

## 文件边界

完整项目保存全部可编辑字段；阵型码按对应格式表达布局与外观；存档集合迁移当前文档和元数据；PNG 用于图片分享。文件覆盖前保留备份，解析和验证成功后再替换工作内容。

自动保存采用最后保存的编辑内容作为当前版本；覆盖前将数据库中的上一版本完整保留到历史。旧编辑基准或其他窗口更新不会阻止自动保存。备注、标签和收藏等存档元数据随记录保留。
