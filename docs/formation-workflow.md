# 阵图、个人存档与游戏现场

工具箱与存档库共用一个独立侧栏窗口，内容区均为410×640，互斥显示，切换不改变宽度。主窗口在PVZ内容上方提供“工具箱”“存档库”两个按钮：当前显示的按钮高亮，再点一次隐藏，点击另一个则切换；隐藏时两个按钮均不高亮。侧栏内部不再有切换条；窗口标题栏已经标明工具箱或存档库，内容区省略重复标题。主按钮使用浅绿底、深绿文字和细边框表示选中，隐藏后保留各自状态，主画布固定尺寸。macOS使用真实独立窗口，Windows/Linux目前使用应用内侧栏备用布局。

存档库顶部横向分类包含预制、我的、收藏、草稿。列表显示缩略图、名称、场地和炮数，点击进入同区域详情，返回保留搜索、筛选和滚动位置。预制名阵包含原站363个完整阵型，点击“加入我的存档”创建独立副本。使用模板成功后，存档库保留分类、搜索、筛选和滚动位置并回到列表；打开失败时保留详情。打开存档后侧栏自动回到工具箱。

新建后未做修改的空白阵图暂不入库；首次实际修改、重命名或明确保存后才创建个人存档，没有独立草稿分类。编辑过又清空的阵图仍保存到原存档，避免丢失工作。启动恢复上次实际打开的存档。点击“筛选”打开独立弹框，按场地和炮数选择条件，点“确定”应用；“重置”清空弹框内待选条件，取消或关闭不改变当前列表。两项可以与搜索组合，每项都有“全部”；没有匹配阵型的场地或炮数选项自动隐藏，匹配的阵型数量使用独立徽标，与炮数名称分开显示，也可清除已应用的筛选。炮数按阵图中的实际玉米加农炮数量计算，零炮统一显示为“无炮”，不根据名称猜测。

## 选卡与种植反馈

工具箱“卡槽选卡”中的“选卡面板 / 模仿者”打开主画布选卡层。普通卡和同种模仿者可同时选择，最多10张卡及1张模仿者；移除卡片会同步调整模仿者索引。“Let's ROCK!”关闭选卡层，不强制切到图鉴页。

音效设置使用原站三份种植声音，陆地随机两种、水格使用水声；泥土／水花动画650ms自动消失。关闭泥土不影响声音，静音不播放。实际支持平台与验证见[反馈说明](planting-feedback.md)。

## 导入与导出

导入阵图文件或粘贴字符串会自动识别PvZ Toolkit、原站布阵器，以及已有PVZF1/完整JSON项目。导出默认Toolkit，可以选择网页格式或完整项目JSON。工具箱阵型码固定为PvZ Toolkit，随当前内容实时更新，只读展示并提供复制；不再需要获取，也没有清空输出。底部卡片搜索已移除。

Toolkit/网页阵型码只保存布阵。文件导出的格式选择框说明不会保存的编辑器元数据；完整JSON用于保存全部显示设置、卡槽和编辑状态。Toolkit还只表达格位，归一动画帧和原网页的像素定位；真实不支持的对象或图像效果会明确报错，不会偷偷删除植物。网页格式不能表达新加入的睡眠属性时会明确拒绝。

导入文件后，在当前编辑会话可“保存到原文件”，继续用该文件原本的格式；“导出 / 另存阵图”选择新格式和位置。来源路径在存档库与主编辑器之间传递，但不写进可分享的阵图文件。覆盖原文件前自动保存带CRC32校验清单的备份，“撤销文件覆盖”恢复并生成可再次恢复的备份。

## 更新个人存档与另存为

每个存档可选择在当前标签页打开或新标签页打开，标签页分别保留编辑内容与撤销记录；复制字符串仅提供PvZ Toolkit。切换或关闭时等待已编辑存档保存，最后一个标签页关闭后保留一个未修改空白页。

每个标签独立维护浏览历史，顶部后退／前进恢复完整会话，包括名称、阵图、文件关联、只读状态和编辑撤销记录。当前页通过存档、名阵、布局、导入字符串／文件、示例或换地图更换阵型时都会保留前一步；后退后再打开其他阵型会清除前进分支。顶部撤销／恢复（重新执行刚撤销的操作）和Cmd/Ctrl+Z统一按操作顺序处理编辑、改名和换阵型，也可使用后退／前进单独浏览页面历史。清空直接执行，无二次确认，撤销可恢复全部植物与底座。关闭标签会关闭该标签的完整浏览历史，退出前会提交所有保留页面。删除存档会从全部历史中移除其对应页面，避免后退重新打开已删除对象。

工具箱采用浅绿和米白的花园配色。“懒人布局”的阵型选择与存档库使用同一份363名阵数据和缩略图、搜索、筛选组件；点击条目默认在当前页打开可编辑副本。只读预览也可选取其他布局，原预览保留在浏览历史。炮位和无炮布局沿用原站局部布局规则。

在存档库选择“当前标签页打开”或“新标签页打开”后，编辑器“保存存档”更新原存档并保留历史版本；“另存为”创建新的存档，原件保留。只读预览也可以另存为副本。文件保存和个人存档保存是两个明确操作。

## 离线 PC 无尽存档

存档库“导入”菜单提供“导入PC无尽存档（实验）”，选择原版 `game*_13.dat` 后预览场地与数量，并可导入当前或新标签。此功能在各平台显示；只提取布阵，不恢复波次、冷却等完整战斗进度，且不会关联或覆盖源 `.dat`。目前文件选择限8MiB。结构测试已通过，真实1051文件仍待验收，详[研究与限制](game-save-import.md)。

## Windows原版1051

仅Windows存档库显示“游戏存档”，其他平台隐藏运行游戏相关入口。所选阵型详情中也有“应用到游戏”。可识别运行中的原版1051，读取当前植物组成、场地、阳光、睡眠属性，并显示实际userdata文件，可备份、另存和恢复。

应用到内存前先在应用数据目录game-backups持久保存带校验的现场阵型快照，备份失败则不会调用写入。覆盖时重读游戏组成与备份核对；撤销也先备份当前内容。不同进程的备份不会串用，历史阵型备份按进程列出。

当前内存写入仅实现原版1051、同场地、生存无尽、普通植物，含常规底座/南瓜/咖啡豆。含模仿者、道具、白天蘑菇、睡眠状态、跨场地、我是僵尸或图像变换时明确拒绝。内存备份是阵型快照，不是整场游戏的波次、生命、冷却和计时器快照；存档文件备份则保留原始文件全部字节。

Windows编译和真实1051游戏读写/撤销尚未在当前macOS环境执行，不应将模拟通道或便携C++测试当作Windows实机验收。技术契约和原始来源见[Windows1051接入](game-integration/windows-1051.md)，协议见[Toolkit阵型码](toolkit-protocol.md)。

## 首屏与绘制

原生主窗口、工具箱和存档库先显示浅色加载界面，再准备素材，避免独立引擎在首帧前等待资源而黑屏。模仿者精确灰度图按需生成并自动重绘；PNG导出等待当前阵型实际需要的灰度图，避免首次导出丢失外观。

棋盘按行的前后关系绘制，下方植物遮挡上方植物，再在同一行内按对象图层排列。花盆、荷叶、植物、南瓜及附属图像保留同格层次，点击命中顺序与绘制一致。

## 种植底座与替换

图鉴／卡槽选卡提供“水面自动垫荷叶”（默认开）和“自动垫花盆：屋顶／屋顶及陆地／关闭”（默认屋顶）。选项保存在应用支持目录的planting-preferences.json，主引擎启动时读取，并与独立工具箱同步。自动底座只补缺失的占格，已有荷叶／花盆不重复，不影响原有外观；多格植物逐格补齐，底座与种植合并为一个撤销命令。

香蒲、缠绕海草和海蘑菇种在水面时不补荷叶，且移除格内已有荷叶；撤销恢复原植物和荷叶。自动花盆使用普通无幼芽外观。

普通种植替换占格内其他植物，保留荷叶、花盆及南瓜；南瓜作为独立包裹层，保留内部植物。玉米加农炮清理前后两格其他植物与南瓜，保留底座；补荷叶／花盆不会删掉上面的植物。懒人布局底部新增的“批量选择与操作”及“批量放置当前植物”扩展面板已移除，原站批选入口保留。

原生工具箱／存档库仅首次打开时定位在主窗口旁；之后左右窗口独立拖动，显示隐藏或切换模式不会重新排列，也不会移动主窗口。

批量操作保留在懒人布局折叠区。主编辑区右上角和批量操作区均提供“完成批量操作”，清除格子选区并退出批选；保存、另存为存档、保存阵图文件成功后也会自动完成，取消文件面板或保存失败不会清掉选区。结束批选不改变阵型、不会新增撤销命令。

智能铲除按可见对象顺序命中，包含伸出逻辑格子的部分；南瓜开口与边缘区分内层植物和壳。删除南瓜时附着梯子同步删除，包括智能铲、按范围铲、批量铲以及选中对象删除。炮替换覆盖范围也会清掉梯子，保留荷叶和花盆。
