# 阵图工作区

主窗口专注阵图，侧窗集中放置存档仓库、懒人布局、图鉴选卡、镜像窗口、载入导出和选项设置。Windows 和 macOS 使用桌面窗口桥接；共享编辑功能与平台状态见 [平台支持](platforms.md)。

## 编辑与外观

阵图支持单个/批量放置、冲突替换、自动补底座、多层对象、外观帧、翻转、显示开关，以及撤销和重做。玉米炮作为一个对象占两格。

选卡默认让大喷菇、忧郁蘑菇和磁力菇显示唤醒外观。默认选择只用于新放置，用户后续选择及载入的外观会保留，输出按最终帧解释。

## 标签与镜像

每个标签保留独立文档和编辑历史；后退/前进可浏览当前标签内的阵型切换。启动恢复上次打开的标签、选中页和文件关联。镜像复制创建时的完整文档，用于只读比较与独立图片导出。

## 保存与分享

编辑自动保存到我的存档，另存为创建独立副本。文件导入识别 Toolkit、网页阵型码和完整 JSON 项目。保存到原文件前保留备份；PNG、背景和阵型码可独立导出。

完整操作见 [使用指南](user-guide.md)。
