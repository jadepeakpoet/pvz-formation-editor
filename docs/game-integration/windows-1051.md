# Windows 游戏阵型读写

适配 Windows 原版 PvZ 1.0.0.1051 生存无尽模式 11–15，支持选卡/布阵场景的阵型读取与应用。

## 功能

- 识别运行中的游戏进程与版本，读取场地、阳光、植物、模仿者、睡眠及支持的稳定状态。
- 读取与创建墓碑、梯子、钉耙；按底座、主植物、外壳与附属物顺序应用布阵。
- 在六种标准场地之间转换阵型，保留游戏当前阳光，应用后读回验证。
- 浏览游戏存档目录，提取支持的无尽存档布阵，备份或另存原始文件。

## 操作

1. 启动适配游戏并进入生存无尽选卡或布阵场景。
2. 在“载入导出”中选择“从游戏获取”，结果会填入输入框；“载入布阵器”将其打开编辑。
3. 当前编辑文档可通过“应用到游戏”写入；存档和名阵详情以及列表“更多”菜单提供相同入口。
4. 写入完成后按应用返回的读取结果核对。

## 外观对应状态

选卡默认仅用于新放置；保存、载入和输出均保留用户最终选择的外观。

| 对象 | 外观与游戏状态 |
| --- | --- |
| 蘑菇 | 睡眠行对应睡眠，其余行对应唤醒；大喷菇、忧郁蘑菇、磁力菇选卡默认使用唤醒行 |
| 玉米炮 | 第一行前两个有弹外观直接可发射；第三个空炮外观为冷却结束，恢复运行后开始装填 |
| 土豆雷 | 地下外观保留准备状态，出土外观直接进入已出土状态 |
| 阳光菇 | 按可表达的大小外观设置成长状态 |
| 仙人掌 | 按高矮外观设置当前形态 |
| 坚果、高坚果、大蒜、地刺王 | 按受损外观设置相应耐久区间 |

玉米炮第二行是发射过程的动作帧；初始布阵使用第一行的稳定外观。完整项目与网页码可保留外观帧，PvZ Toolkit 码表达标准格位、模仿者与睡眠状态。

## 实现

Flutter 通过 `pvz_formation_editor/game` 通道调用 Win32 适配。版本检测使用运行中主映像信息与调用入口检查。写入前重新核对进程、模式及现场快照，构造完成后检查组成、场地、阳光和相关植物状态，再恢复游戏主循环。

主要接口：`listGames`、`readFormation`、`applyFormation`、`listSaveFiles`、`saveFolders`。应用临时快照用于本次一致性检查；本地存档历史和文件备份由各自模块管理。

参考 [PvZ Toolkit](https://github.com/lmintlcx/pvztoolkit) 的版本与阵型格式，以及 [PvZ-Portable](https://github.com/wszqkzqk/PvZ-Portable) 的植物状态机。Windows Release 和实际 1051 游戏阵型读写已验证。

有弹玉米炮应用完成时以明亮的就绪外观显示；游戏恢复运行后继续原版就绪闪烁。空炮在冷却结束状态进入游戏并立即开始装填。
