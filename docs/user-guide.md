# 使用指南 · v1.0.1

植物大战僵尸布阵器使用 Flutter 构建，提供本地阵图编辑、自动存档、格式交换和图片分享，Windows 版还可直接读取和应用游戏阵型。

## 打开与工作区

Windows 用户完整解压绿色包，运行 `pvz_formation_editor.exe`。主窗口显示阵图；侧窗依次提供存档仓库、懒人布局、图鉴选卡、镜像窗口、载入导出和选项设置。Windows 主窗口可以单独最小化。

首次使用显示图鉴选卡和一个空白编辑页。以后启动恢复上次打开的标签及所选页面。关闭全部阵型页后，工作区保留一个空白页。每个标签拥有自己的编辑内容、后退/前进历史和撤销/重做记录。

## 编辑阵图

选择地图、植物或场地物品后，可单个或批量放置。底座、主植物、南瓜和咖啡豆按层次组合；自动补底座、冲突替换和批量铲除用于快速整理。图层、翻转、显示开关及外观选择控制阵图效果。

“图鉴选卡”用于放置对象；“选卡面板”用于设置顶部十格卡槽，普通卡与同种模仿者卡可同时选择。

选卡默认将大喷菇、忧郁蘑菇和磁力菇设为唤醒外观，其他可睡眠蘑菇默认睡眠。用户继续选择外观后，保存和游戏应用均以最终帧为准。载入存档、导入文件或阵型码时保留已有外观。

## 我的存档与自动保存

从名阵打开可编辑阵型时自动保存到“我的存档”。新建空白页首次有效修改、重命名或显式保存后入库；后续修改更新同一个存档，并保留历史版本。

顶部显示自动保存状态。Ctrl+S（macOS 为 ⌘S）提交保存，另存为创建独立副本。切换标签和正常退出会刷新保存队列。历史版本可预览和恢复，恢复前的内容继续保留。

存档仓库顶部提供搜索、场地/炮数筛选、批量选择、导入、导出和去重。筛选后的全选作用于当前结果；切换筛选时保留已选项目，导出前可检查数量。

## 载入与导出

输入框接受 PvZ Toolkit 和网页布阵器阵型码。“载入布阵器”将其打开到编辑页。“粘贴导入”读取剪贴板，校验通过后直接载入；空内容或无效码不会更改当前阵型。读取与复制各有 Toolkit、网页两项互斥格式选择，默认 Toolkit。存档详情与列表“更多”菜单提供两种复制方式，问号提示说明区别。PvZ Toolkit 码用于复制和分享；“应用阵型”直接替换游戏中的布阵，可包含僵尸及其所选状态。

PvZ Toolkit 码提取标准植物布局；网页码可保留僵尸坐标和所选外观。

完整项目 `*.pvzf.json` 保存阵图、外观、卡槽和显示设置；`*.pvzlib.json` 用于批量迁移当前存档及其名称、备注和标签。导入时按内容去重，同名不同内容会自动调整名称。

来自文件的阵型支持“保存到原文件”。覆盖前保留备份，可通过恢复操作取回。默认导出目录为文稿目录下的 `PvzFormationEditor`，每次保存仍可自行选择路径。

## 图片与镜像

PNG 导出可设置倍率和背景，默认保持游戏原比例。“生成图片”完成后，在工具箱内靠近点击位置弹出预览，可直接导出或复制；关闭预览后释放本次图片缓存。支持单独导出地图底图。镜像是创建时的只读快照，最多三个，可分别调整比例、背景和导出图片，便于对照布局。

363 张名阵缩略图随应用提供，列表按需显示；自定义阵型的缩略图生成后缓存到本地。

## Windows 游戏接入

适配原版 Windows PvZ 1.0.0.1051 生存无尽模式 11–15。进入选卡或布阵场景后，在“载入导出”输入框上方点击“从游戏获取”，读取结果先填入输入框，再由“载入布阵器”打开编辑。

主区域“卡槽选卡”和“工具箱”之间的 ▶ **应用阵型** 使用当前阵图替换实际布阵。载入导出中该操作单独一行；存档/名阵详情及列表“更多”菜单提供同一操作，悬停可查看说明。

读取网页格式时，按真实动画、携带物、入水及啃食状态选择僵尸外观帧。21 种僵尸的 103 个稳定外观组合支持应用与读回，例如无盒小丑、无气球落地、潜水与出水啃食、失去报纸或工具。过渡动作或死亡帧会在应用时提示切换稳定外观。

海豚按原图锚点转换到游戏位置，暂停时初始化最终姿态。植物高亮对应游戏的受啃食闪光，继续运行后按原版周期更新。游戏应用支持六种标准场地；自定义六行草地、六行屋顶等地图可用于编辑和图片分享，应用时会提示支持范围。

有弹玉米炮会直接处于装填完毕、可发射状态；空炮冷却归零，恢复运行后开始装填。土豆雷出土、阳光菇大小、仙人掌高矮，以及坚果、高坚果、大蒜、地刺王的受损程度，按支持的外观映射到实际状态。写入完成后会读回并核对。

PvZ Toolkit 码保存标准格位、模仿者和蘑菇睡眠；完整项目及网页码可保留更多外观字段。需要保留植物外观对应的状态时，保存完整项目并直接应用该文档。

游戏存档入口可浏览目录、备份与另存原版存档文件，并从支持的无尽存档提取布阵。详见 [Windows 游戏接入](game-integration/windows-1051.md)。

## 设置与交流

选项设置提供语言、显示、音效、土壤水花和导出目录等选项。土壤水花默认关闭，可随时开启。应用与官网支持简体中文、English。

[官网](https://xmpvz.pages.dev) · [GitHub](https://github.com/jadepeakpoet/pvz-formation-editor) · [交流 QQ 群 425175276](https://qm.qq.com/q/BbkV57ELaa)。

应用阵型可勾选“清除场上僵尸”，默认不勾选；懒人布局提供一键清除僵尸，保留现有植物与阳光。包含僵尸的阵型仍按目标布局替换僵尸。存档详情先选择 PvZ Toolkit 码或网页布阵器码，再点击“复制阵型码”。
