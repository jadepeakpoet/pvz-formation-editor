# 功能总览

PVZ Formation Editor 基于 Flutter 提供跨平台本地编辑，以 Windows 为主要发布平台。

| 模块 | 能力 |
| --- | --- |
| 阵图 | 26 地图、多类对象、图层与外观、翻转、批量种植/铲除、撤销与重做 |
| 选卡 | 图鉴、模仿者、十格卡槽和植物默认外观 |
| 布局 | 363 名阵、局部布局、场地/炮数筛选和搜索 |
| 工作区 | 独立主窗口与侧窗、标签页、上次工作区恢复、最多三个镜像 |
| 存档 | 自动保存、备注/标签、历史版本、批量导入导出和去重 |
| 分享 | Toolkit 码、网页码、完整项目、存档集合和 PNG |
| Windows 游戏 | 实际阵型读取与应用、状态读回验证、存档目录及文件接入 |
| 资源 | 按需植物帧、重复图片共享、包内缩略图与本地缓存 |
