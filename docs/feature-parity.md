# 原站功能与当前验收范围

目标是尽量复现 <http://jspvz.com/ArrayDesign/> 的布阵能力，同时以用户最新要求覆盖原站交互：固定主画布、共享独立侧栏、标签页、个人存档、Toolkit 实时阵型码和紧凑筛选。

## 当前交互

- 主窗口保留 PVZ 标题装饰与 800×600 画布，macOS 主内容区固定 810×695，无页面纵向滚动。侧栏控制位于 PVZ 内容外。
- 工具箱与存档库共用一个 macOS 原生窗口，主窗口上方“工具箱／存档库”按钮切换，显示时高亮、再次点击隐藏；两个模式内容均为 410×640，侧栏内部没有切换头。关闭只隐藏，浏览与工具状态保留。Windows/Linux 当前使用共同的应用内备用布局，尚未实现相同的独立原生侧栏。
- 原工具箱六页、26 地图、363 完整名阵和 57 局部布局保留。选择、铲除、批量、一键、外观、翻转、镜像、PNG、显示与音量按各用例分别验收。
- 存档库采用横向分类、紧凑缩略图列表与同区域详情；场地/炮数弹框组合筛选，零炮称无炮，隐藏零匹配选项。炮数与阵型数量使用独立视觉元素。
- 每个存档可在当前或新标签页打开，复制仅 Toolkit；更新原存档、另存为、历史、文件覆盖前备份与恢复分别保留。原始未修改空白阵图不落工作草稿。
- 工具箱阵型码固定 Toolkit、自动跟随文档、只读复制；去掉获取、清空输出和底部卡片搜索。文件导出仍可选网页格式或完整项目 JSON。
- 本轮依据取得的原站 `main.js` 补齐模仿者选卡面板和种植声/土壤水花生命周期。独立测试和主界面接线验收见本轮记录，不能套用旧版 755 用例结果。

## 已执行的功能回归

2026-10-20 领域与存储等 695 项通过；经典工具箱 UI 755 项完整执行（含 420 个预设），初始两项旧资源包缺图错误保留，使用最新资源重测两款窗口皮肤通过后最终 755 项通过。每项都有真实 Flutter 截图，所有截图文件及尺寸已核对。

这次全量 UI 编译基线在侧栏融合前，验证经典控件；新窄版侧栏、跨引擎窗口、系统剪贴板与新增功能有独立的最新测试，见 [回归说明](parity-regression.md) 和 [任务记录](parity/ledger.md)。模拟文件选择、剪贴板或通道的用例不能当作原生系统验收。

## 仍需独立验收的边界

- 原站截图严格像素一致尚未达成；先前 469 个有参照场景仍有差异，不能将渲染成功或功能测试通过改称 1:1 视觉通过。JPEG 压缩、字体、控件、部分僵尸与效果位置等差异应继续按比较报告追踪。
- 原站隐藏的 DIYTime/动态 iframe、全部自动附属动画及特殊地形规则没有完整实现和逐场景验收。选卡面板和复杂效果也不能仅凭源字段解码宣称逐像素一致。
- Windows 1051 的进程/存档工具仅在 Windows 展示；当前 macOS 环境未执行 Windows 原生编译或真实游戏读写/撤销。当前写入的对象与场景限制见 [Windows1051](game-integration/windows-1051.md)。
- 离线 PC 存档导入是实验性布阵提取，不是完整战斗恢复；只有主来源结构构造的测试文件，真实 1051 `.dat` 仍未验收。见 [研究与限制](game-save-import.md)。

当前目录没有 Git 仓库，也没有确认的远程地址，无法提交或推送；本地构建、运行、测试与截图证据按阶段保留。
