植物大战僵尸布阵器 1.0.1 — 越小梦

Windows 10 / 11 x64 绿色版：完整解压后运行 pvz_formation_editor.exe。
保留同目录 DLL 和 data 文件夹；无需安装。
本地数据保存在用户应用数据目录，迁移前请从存档库导出。

官网：https://xmpvz.pages.dev
使用文档：https://xmpvz.pages.dev/docs/
开源项目：https://github.com/jadepeakpoet/pvz-formation-editor
交流 QQ 群：425175276

游戏读写支持 Windows 原版 1.0.0.1051 生存无尽模式，其他版本未保证兼容。
应用到游戏会替换已有布阵，没有注入历史回退，请事先保留重要阵型码。
