植物大战僵尸布阵器 1.0.1 — 越小梦

Windows 10 / 11 x64 绿色版：完整解压后运行 pvz_formation_editor.exe。
保留同目录 DLL 和 data 文件夹；无需安装。
本地数据保存在用户应用数据目录，迁移前请从存档库导出。

官网：https://xmpvz.pages.dev
使用文档：https://xmpvz.pages.dev/docs/
开源项目：https://github.com/jadepeakpoet/pvz-formation-editor
交流 QQ 群：425175276

基于 Flutter Widget / Canvas，提供本地阵型编辑、363 个内置名阵、
自动存档、上次标签恢复、阵型码交换与 PNG 导出。
Windows 专属：原版 1.0.0.1051 生存无尽模式 11–15 的阵型读取、应用及游戏存档接入。
“从游戏获取”将阵型填入载入框；“应用阵型”将选定布局设置到游戏。
“粘贴导入”校验剪贴板中的阵型码后直接载入；生成图片后在工具箱弹窗中复制或导出。
网页格式可交换僵尸布局，游戏应用按支持的外观保留携带物、潜水和啃食等状态。
可通过完整项目或阵型码保留重要布局，通过存档历史恢复编辑版本。

主要参考：jspvz 网页布阵器，LonelyStar（囧丫乙），http://jspvz.com/ArrayDesign/
技术参考：PvZ Toolkit（lmintlcx），PvZ-Portable（wszqkzqk）。
